# AI policy

You can use AI tools, coding agents included, when you contribute to AurigaX projects. What we ask is
that a person stays responsible for everything that reaches us.

1. **You answer for every line you send.** Understand each line of your issue or change, be able to
   explain it without the tool, and take responsibility for it as if you had written it yourself.
2. **A person reviews and sends it.** We do not accept issues, pull requests or comments that an
   autonomous agent opens without a person reviewing them and sending them.
3. **Check AI-found security problems yourself.** If a tool reports a vulnerability, confirm it is
   real before you report it, and report it privately as the
   [security policy](https://github.com/aurigax-ai/.github/blob/main/SECURITY.md) describes.
4. **We may close what does not follow this policy.** Issues, pull requests and comments that do not
   follow it may be closed without further explanation.

You do not need to tell us whether or how you used AI.

The maintainers' own agents follow the `AGENTS.md` file in each repository.
