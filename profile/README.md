## Ostia

<a href="https://github.com/aurigax-ai/ostia"><img src="https://raw.githubusercontent.com/aurigax-ai/.github/main/profile/assets/ostia-icon.png" width="72" height="72" alt="Ostia icon"></a>

[Ostia](https://github.com/aurigax-ai/ostia) is one workspace for you and your coding agents: a
terminal for macOS and Linux where Claude Code, Codex and your own shell share panes, a browser,
diffs and approvals.

<img src="https://raw.githubusercontent.com/aurigax-ai/.github/main/profile/assets/ostia-hero.webp" alt="Ostia with six projects in the sidebar, an agent session and the diff of its change" width="720">

[Website](https://aurigax-ai.github.io/) · [Download](https://github.com/aurigax-ai/ostia/releases/latest) · [Write an extension](https://www.npmjs.com/package/@aurigax-ai/ostia-extension-sdk)

On macOS 13 or later (Apple silicon):

```sh
brew install --cask aurigax-ai/tap/ostia
```

On Debian and Ubuntu (x64), add the [APT repository](https://github.com/aurigax-ai/apt#install).
On other Linux (x64), use the tarball from the
[latest release](https://github.com/aurigax-ai/ostia/releases/latest).

## Repositories

| Repository | What it is |
|---|---|
| [ostia](https://github.com/aurigax-ai/ostia) | The Ostia app |
| [ostia-extensions](https://github.com/aurigax-ai/ostia-extensions) | Extension marketplace for Ostia, mirrored from the ostia repository |
| [ghostty-web](https://github.com/aurigax-ai/ghostty-web) | Ghostty's terminal engine (official libghostty-vt) in the browser with an xterm.js-shaped API; the engine behind the Ghostty terminal in Ostia. A hard fork of [coder/ghostty-web](https://github.com/coder/ghostty-web), published as `@aurigax-ai/ghostty-web` |
| [homebrew-tap](https://github.com/aurigax-ai/homebrew-tap) | Homebrew tap for Ostia |
| [apt](https://github.com/aurigax-ai/apt) | APT repository for Ostia (Debian and Ubuntu) |
| [aurigax-ai.github.io](https://github.com/aurigax-ai/aurigax-ai.github.io) | The Ostia website |
