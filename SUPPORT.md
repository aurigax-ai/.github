# Getting help

AurigaX is a team of two. We read everything and answer when we can, but there is no guaranteed
response time.

| You want to | Go to |
|---|---|
| Install Ostia | The [download page](https://aurigax-ai.github.io/download/) |
| Report a bug or ask for a feature | An issue in [aurigax-ai/ostia](https://github.com/aurigax-ai/ostia/issues/new/choose), with the Bug report or Feature request form |
| Ask how to do something | An issue with the Question form. We do not use GitHub Discussions |
| Report a security problem | The [security policy](https://github.com/aurigax-ai/.github/blob/main/SECURITY.md): privately, never in a public issue |
| Anything else, such as partnerships or press | aurigax.ai@gmail.com |

Search the [existing issues](https://github.com/aurigax-ai/ostia/issues?q=is%3Aissue) before you
open a new one.
